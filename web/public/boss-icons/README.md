# Boss icons

MapleStory boss artwork is owned by NEXON. These 25 PNG icons were retrieved
on 2026-11-10 from the boss icon collection used by
[MapleIsland's boss information guide](https://mapleisland.app/guides/boss-information).
Each source is `https://mapleisland.app/boss/<filename>` using the filename here.

Icons are served locally. The boss picker prefers a boss's configured image URL
and uses these bundled icons for the known catalog names when none is configured.
